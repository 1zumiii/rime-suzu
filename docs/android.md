# Android（Trime）

Android 使用改版 Trime，方案、Lua 和默认词库随 APK 提供。首次启动时可按引导下载模型，之后在“设置 → 词库”中切换词库包、启用附加词库或管理模型。

AI 推理运行在独立的常驻进程 `rimellmd` 中，界面称为“AI 服务”。Trime 内仅保留轻量客户端，输入法进程被终止或崩溃时，模型不受影响。设计、实测数据和文件清单见 [suzu-ime 的 Android 说明](https://github.com/1zumiii/suzu-ime/blob/main/android/README.md)。

## 安装与 AI 服务

- 改版 Trime：从上游分叉后独立维护，源码位于 [suzu-ime](https://github.com/1zumiii/suzu-ime/tree/main/android/trime)。新增 `INTERNET` 权限，用于本机 127.0.0.1 通信，以及下载模型和词库。同时提供亮灭屏通知、工具栏 `● AI` 状态徽标和 Shizuku 启动入口。APK 从 [suzu-ime 的发布页](https://github.com/1zumiii/suzu-ime/releases/latest)下载，也可自行编译并使用自有密钥签名。
- 守护进程：由 adb 或 Shizuku 以 shell 身份启动。监督进程看护工作进程，工作进程被终止、崩溃或无响应时按退避时间自动重启，并记录原因。与 Trime 之间经 127.0.0.1 通信，使用随机令牌认证。所有 I/O 都有时限，连不上时当次不重排，输入不受影响。
- 手动启停：点按工具栏的 `● AI` 徽标开关 AI。绿色为在线，黄色为加载或重启中，灰色为已关闭，红色为离线（点按后经 Shizuku 启动）。长按可查看内存、延迟、重启次数和上次退出原因。关闭时立即卸载模型，进程只保持待命，开启时立即加载。新装时默认开启。在“设置 → AI 与输入辅助”中关闭 AI 重排后，工具栏不显示徽标。守护进程把最后一次手动选择记在用户目录的 `ai_enabled.state`，Trime 重启、重新部署或守护进程重启后保持不变。

## 配置、词库与模型

- 配置更新：配置与 APK 版本绑定，更新配置须安装新的 APK。词频、用户词、最近使用记录、语法模型和推理模型在用户目录，安装时不受影响。旧版本升级时，App 自动把旧用户词典合并到 `suzu.userdb`，并清理用户目录里的旧配置。
- 词库包：共用一个 ID 为 `suzu` 的方案，默认白霜词库随 APK 提供。其他包可在“设置 → 词库”中下载和切换，校验 sha256 后重新部署，失败时尝试恢复原词库包。所有词库包共用一份用户词典。
- 模型文件：在“设置 → 模型”中换模型时，新模型直接替换旧模型，不保留旧文件。中途取消的下载会在“管理已下载的模型”中列为“未下载完”，可以删除。删除模型时，AI 服务目录里的模型副本一并删除。卸载 App 后，AI 服务在 10 分钟内退出，并删除它复制的文件。也可以手动将配套的 `suzu.gguf` 和 `suzu.vocab.txt` 放入 Trime 用户目录，再重启守护进程。长按 AI 徽标可查看已加载的模型。已知权重显示版本名，其他权重显示 GGUF 模型名和 SHA-256 的前 8 位。
- 功能状态：三个点的面板中提供“功能状态”入口，只读显示 AI 服务、排序方式、候选生成和各类记录的状态。
- 手机端设置：2 个推理线程、10 个候选（与 macOS、Windows 相同）、候选生成每层展开 10 个首字。这些设置写在 `llm-android/trime/rime_ice.overlay.yaml` 中，构建 APK 时才追加，不影响 macOS 和 Windows。

## 键盘与词库

- GBoard 风格键盘：布局和动作写在代码里，不再读取主题文件。按键默认带圆角矩形背景，可在设置的键盘页关闭。空格键在中文模式下显示“拼音”，英文模式下显示“English”。`?123` 页的标点跟随当前语言，中文模式下输出中文标点，英文模式下输出半角标点。数字后的 `,`、`.`、`:` 仍按半角暂存，接着打拼音时换回中文标点。表情、标点和颜文字共用一个符号页组件，按符号数量自动分页。
- 模型下载：首次启动的引导页提供 Suzu 模型和语法模型下载，也可导入已下载的语法模型文件。跳过时对应功能保持关闭，之后可在“设置 → 模型”中下载或删除。手机端启动 AI 服务仍需 Shizuku。
- 附加词库：设置的“词库”页可以启用萌娘百科词库。App 从上游下载词表，在手机上过滤并统一权重，再重新编译（模拟器上约 1 分钟）。词条来自萌娘百科，由 mw2fcitx 项目整理，本仓库不转发。
- 配色：内置浅色和深色两套，可选跟随系统、浅色或深色。在三个点的面板里点按“配色”轮换，也可在设置的键盘页选择。

## AI 与输入辅助

“设置 → AI 与输入辅助”汇集了以下开关，新装时全部开启。开关显示的是实际状态：条件不满足时开关为关且不可点，下方写明缺少什么。

关闭 AI 重排后，工具栏不显示 `● AI` 徽标，三个点面板里也没有 AI 项。开着时，点按徽标可临时暂停或恢复 AI。

| 分组 | 开关 | 作用 | 开启条件 |
|---|---|---|---|
| AI 重排 | AI 重排 | 按上文为候选打分并调整顺序。关闭时隐藏工具栏的 AI 徽标 | 已下载 Suzu 模型，Shizuku 正在运行。AI 服务未运行时，开启会经 Shizuku 启动它，首次会请求授权 |
| | 两段推理 | 四个字以上的输入，先拼出第一段，再对剩下的拼音打分，拼成整句 | AI 重排已开启 |
| | 候选生成 | 简拼时补充 Rime 没给出的词 | AI 重排已开启 |
| 修正 | 选错修正提示 | 见下文 | AI 重排已开启 |
| | 光标换词 | 见下文 | AI 重排已开启 |
| 个人习惯 | 最近使用优先 | 最近上屏过的词排得更靠前 | 无 |
| | 个人词对 | 常用的前后搭配再次出现时优先 | 无 |
| | 纠错记忆 | 在同样的前一个词和拼音下，优先选过的词 | 无 |

个人习惯三项关闭后不参与排序，也不再记录，已有的记录保留。

- 选错修正提示：每次整段选词时，记下所选词和同页的其他候选。停顿 1.5 秒后，补上右侧已打的文字，给句中最近几个选词与各自的候选打整句分。某个候选比原词高出门控时，工具栏显示“A → B”，点按后核对原文再替换，点 ⊗ 或继续打字则收起。门控为 8，原首位是 AI 改过的为 5。停顿时间在开关说明下方的“停顿时间（秒）”处展开，用滑块调整，默认 1.5 秒，范围 0.5～5 秒，每步 0.5 秒。
- 光标换词：将光标移到文字处，候选栏列出可替换的同音候选，点选后只替换对应片段。词语与单字候选统一按替换后的整句分数排序，不显示分数明显降低的候选。
- 两项的文字都只在内存里，密码框和无痕模式下不启用。

“设置 → 高级 → 诊断记录”另有选词统计、选词语料和输入事件流三个开关，新装时关闭，记录只写在本机用户目录。切换后自动重新部署一次。

## 适用范围

- 适用范围：只在这一台手机上验证过，其他机型和 Trime 版本未测试。手机重启后须先启动 Shizuku，才能启动守护进程。
