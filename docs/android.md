# Android（Trime）

Android 使用改版 Trime，方案、Lua 和默认词库随 APK 提供。首次启动时可按引导下载模型，之后在“设置 → 词库”中切换词库包、启用附加词库或管理模型。

AI 推理运行在独立的常驻进程 `rimellmd` 中，界面称为“AI 服务”。Trime 内仅保留轻量客户端，输入法进程被终止或崩溃时，模型不受影响。设计、实测数据和文件清单见 [suzu-ime 的 Android 说明](https://github.com/1zumiii/suzu-ime/blob/main/android/README.md)。

## 安装与 AI 服务

- 改版 Trime：从上游分叉后独立维护，源码位于 [suzu-ime](https://github.com/1zumiii/suzu-ime/tree/main/android/trime)。新增 `INTERNET` 权限，用于本机 127.0.0.1 通信，以及下载模型和词库；同时提供亮灭屏通知、工具栏 `● AI` 状态徽标和 Shizuku 启动入口。仓库不含 APK，须自行编译并使用自有密钥签名。
- 守护进程：由 adb 或 Shizuku 以 shell 身份启动。监督进程看护工作进程，工作进程被终止、崩溃或无响应时按退避时间自动重启，并记录原因。与 Trime 之间经 127.0.0.1 通信，使用随机令牌认证。所有 I/O 都有时限，连不上时当次不重排，输入不受影响。
- 手动启停：点按工具栏的 `● AI` 徽标开关 AI。绿色为在线，黄色为加载或重启中，灰色为已关闭，红色为离线（点按后经 Shizuku 启动）。长按可查看内存、延迟、重启次数和上次退出原因。关闭时立即卸载模型，进程只保持待命；开启时立即加载。新装时默认关闭。守护进程把最后一次手动选择记在用户目录的 `ai_enabled.state`，Trime 重启、重新部署或守护进程重启后保持不变。
- 孤儿保护：Trime 被卸载后，其数据目录随之消失。守护进程发现该目录连续 10 分钟不存在时自行退出，监督进程随之结束。重新安装 Trime 后，点按红色徽标即可再次启动。

## 配置、词库与模型

- 配置更新：配置与 APK 版本绑定，更新配置须安装新的 APK。词频、用户词、最近使用记录、语法模型和推理模型在用户目录，安装时不受影响。旧版本升级时，App 自动把旧用户词典合并到 `suzu.userdb`，并清理用户目录里的旧配置。
- 词库包：共用一个 ID 为 `suzu` 的方案，默认白霜词库随 APK 提供。其他包可在“设置 → 词库”中下载和切换，校验 sha256 后重新部署；失败时尝试恢复原词库包。所有词库包共用一份用户词典。
- 模型文件：`suzu.gguf` 和 `suzu.vocab.txt` 放入 Trime 用户目录后重启守护进程即启用。可选的 `suzu.name`（一行文字，如 `Suzu-2.4`）用于在长按徽标的详情里显示模型名。
- 功能状态：三个点的面板中提供“功能状态”入口，只读显示 AI 服务、排序方式、候选生成和各类记录的状态。
- 手机端设置：2 个推理线程、9 个候选、候选生成每层展开 10 个首字、第二阶段默认“两段”，可在三个点的开关面板里切到“单段”。这些设置写在 `llm-android/trime/rime_ice.overlay.yaml` 中，构建 APK 时才追加，不影响 macOS 和 Windows。

## 键盘与可选功能

- GBoard 风格键盘：布局和动作写在代码里，不再读取主题文件。主页面、`?123` 数字符号页和数字页都不画键帽，按下时才显示高亮。空格键在中文模式下显示“拼音”，英文模式下显示“English”。`?123` 页的标点跟随当前语言，中文模式下输出中文标点，英文模式下输出半角标点；数字后的 `,`、`.`、`:` 仍按半角暂存，接着打拼音时换回中文标点。表情、标点和颜文字共用一个符号页组件，按符号数量自动分页。
- 模型下载：首次启动的引导页提供 Suzu 模型和语法模型下载，也可导入已下载的语法模型文件。跳过时对应功能保持关闭，之后可在“设置 → 模型”中下载或删除。手机端启动 AI 服务仍需 Shizuku。
- 附加词库：设置的“词库”页可以启用萌娘百科词库。App 从上游下载词表，在手机上过滤并统一权重，再重新编译（模拟器上约 1 分钟）。词条来自萌娘百科，由 mw2fcitx 项目整理，本仓库不转发。
- 配色：内置浅色和深色两套，可选跟随系统、浅色或深色。在三个点的面板里点按“配色”轮换，也可在设置的键盘页选择。
- 光标换词：将光标移到文字处，候选栏会列出可替换的同音候选，点选后仅替换对应片段。词语与单字候选统一按替换后的整句分数排序，不显示分数明显降低的候选。文字仅保留在内存中。

## 适用范围

- 适用范围：只在这一台手机上验证过，其他机型和 Trime 版本未测试。手机重启后须先启动 Shizuku，才能启动守护进程。
